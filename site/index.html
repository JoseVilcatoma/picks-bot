Conectar con GitHub

Se hace una sola vez por dispositivo (celular y PC por separado).

  1. GitHub → foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nombre: calendario. Expiración: la más larga.
  3. Repository access → Only select repositories → elige tu repo de picks.
  4. Permissions → Contents: Read and write · Actions: Read and write.
